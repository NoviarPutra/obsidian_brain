# cheatsheet

## 1. Core Vocabulary & Idiomatic Expressions

- **Cheatsheet** /ˈtʃiːt.ʃiːt/ (*noun*) — A quick reference guide that contains concise summaries of essential information.
  - *Example*: I always keep a handy cheatsheet open whenever I write new functions in Python.
- **Look up** /lʊk ʌp/ (*phrasal verb*) — To search for specific facts, words, or commands in a reference source.
  - *Example*: If you forget an unfamiliar terminal command, you can quickly look it up online.
- **At a glance** /æt ə ɡlɑːns/ (*idiom*) — Immediately upon looking, without requiring a detailed or time-consuming search.
  - *Example*: This clear overview allows developers to check critical syntax rules at a single glance.
- **Jot down** /dʒɒt daʊn/ (*phrasal verb*) — To write something down quickly on paper or in a simple text file.
  - *Example*: She always jots down useful tips while she is watching technical video tutorials.
- **Handy** /ˈhæn.di/ (*adjective*) — Convenient to hold, store, or use; practically useful for daily tasks.
  - *Example*: A concise summary card is very handy when you are preparing for technical tests.
- **Summary** /ˈsʌm.ər.i/ (*noun*) — A brief statement or text that presents only the main ideas of a topic.
  - *Example*: Before the exam started, we reviewed a short summary that covered every important unit.

## 2. Grammar & Sentence Pattern Focus

### Pattern 1: First Conditional (`If + Present Simple, ... will + Base Verb`)
- **Structure**: `If + [Subject + Present Simple], [Subject + will/won't + Verb]`
- **Explanation**: Used to talk about realistic future possibilities and their direct practical results.
- **Examples**:
  1. If you create a personal cheatsheet, you will remember difficult concepts much more easily.
  2. If we organize our notes neatly, we will not waste time during our revision sessions.
  3. You will pass the final assessment if you review these grammar summaries every morning.

### Pattern 2: Defining Relative Clauses with *Which* / *That* / *Who*
- **Structure**: `[Main Clause] + [which / that / who] + [Relative Clause]`
- **Explanation**: Connects extra descriptive details to a noun without creating separate, clunky sentences.
- **Examples**:
  1. A cheatsheet is a useful document that collects vital information in one place.
  2. I usually study with classmates who share clear study materials before important exams.
  3. He built a digital reference card which contains all common Git commands.

## 3. Reading Passage & Dialogue

*Leo and Maya are studying together in the university library for an upcoming certification.*

**Leo**: "Have you finished preparing your revision materials for our upcoming certification test next Friday?"

**Maya**: "Not completely, but I have already created a handy cheatsheet that summarizes all essential commands."

**Leo**: "That sounds really helpful! Do you actually find cheatsheets useful when you study complex topics?"

**Maya**: "Definitely! If I jot down key points by hand, I will remember them much better."

**Leo**: "I usually get overwhelmed because textbooks contain too much detailed theory and long explanations."

**Maya**: "A good cheatsheet solves that problem because it allows you to check key concepts at a glance."

**Leo**: "Which specific topics have you included in your summary so far for this testing module?"

**Maya**: "I have focused on common syntax rules and phrasal verbs that are often tested on exams."

**Leo**: "If you share that reference guide with me, I will help you with practice questions."

**Maya**: "Deal! If we review these notes together every afternoon, we will pass without any stress."

**Leo**: "Awesome, let's print two copies so we can look up difficult definitions whenever we need."

**Maya**: "Great idea! Creating your own reference sheet is already half of the learning process itself."
