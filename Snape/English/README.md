## ⚡ Spaced Repetition (SR) Integration Guide

If you use the **Obsidian Spaced Repetition** plugin:
- Tag any line with `#card` or use the format: `Term / Question :: Definition / Answer #card`
- Review flashcards directly on mobile or desktop by clicking the Flashcard icon in Obsidian.
